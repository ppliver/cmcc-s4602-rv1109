--- 失败路径对照（重要）---
[1] MPP_BUFFER_TYPE_NORMAL(0x1) 帧缓冲：
    解码帧 Y min/max/mean 0 0 0.0（后续帧 0 242 0.4），UV 全 0 -> 纯绿画面
    原因：普通堆内存无 cache 同步，CPU 写的 NV12 硬件 DMA 读不到。
[2] raw 路径沿用 MPP_SET_INPUT_TIMEOUT=100 / OUTPUT_TIMEOUT=1 + 独立 header group：
    mpp_service_cmd_send ioctl MPP_IOC_CFG_V1 failed ret -1 errno 12 Cannot allocate memory
    hal_h264e_vepu541_start send cmd failed 12（每帧仅 ~100 B 空洞包）
[3] --nfrmbuf 2：同样 ENOMEM。此版 VEPU541 HAL 只允许 1 个帧缓冲。
[4] 未加色度降噪：严重 Bayer 假色/彩噪（HDR_X2 行交错）。
