推流设置

修改写入 /data/www/stream.conf（断电保留），切换约 5 秒黑屏。分辨率/编码可随意来回切换，无需重启设备（行 stride 残留问题已修复）。通道规格：1440p=ISPP 旁路直通（全视野 ~20fps）；1080p=1440p 旁路采集后中心裁切（视野略窄）；720p 走硬件缩放（视野最广，≈23fps）。真·1080p 缩放需占用云端流的主通道（scale0），未启用。弱网平滑：把一帧的数据包在窗口内均匀发送，降低 WiFi 突发丢包——链路好设 0（突发，延迟最低），弱网/花屏时试 5~10，默认 3。帧内刷新：每帧渐进刷新 N 行宏块，丢包花屏自动逐步愈合、不再依赖整帧 IDR——花屏严重时调大（3~4），链路好设 0（画质最优）。推流目标改非默认值时，QGC/PixelPilot 视频源地址需同步修改。

预览服务（go2rtc + rtp2pipe）

--
go2rtc = WEB 预览（stream.html 的 WebRTC/HLS/MSE）+ RTSP :8554，rtp2pipe 是其拉流子进程，随开关一起启停。关闭可显著降低 CPU，重启设备后仍保持关闭；内网 UDP 推流（QGC）与云链路不受影响。开启即刻生效。
